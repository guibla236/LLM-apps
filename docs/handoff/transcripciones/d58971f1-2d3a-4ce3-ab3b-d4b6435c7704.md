
en Kaggle no subes archivos a mano, sino que el dataset aparece en el contenedor en  
`/kaggle/input/<NOMBRE_DEL_DATASET>/…`.  

Por tanto, para usar la versión de Kaggle basta con:

1. **Cambiar la ruta del `open()`** por la ubicación concreta de tu dataset. por ejemplo:  
   ```python
   kaggle_path = '/kaggle/input/mi-dataset-de-tickets/tickets.json'
   with open(kaggle_path, 'r', encoding='utf-8') as f:
       tickets_data = json.load(f)
   ```
   o bien, definir `kaggle_path` condicionalmente según la presencia del directorio.

2. (Opcional) si utilizas la API de Kaggle desde el notebook para descargarlo, añade antes un bloque tipo:  
   ```python
   !pip install -q kaggle
   from kaggle.api.kaggle_api_extended import KaggleApi
   api = KaggleApi(); api.authenticate()
   api.dataset_download_files('usuario/mi-dataset-de-tickets', path='.', unzip=True)
   ```

El resto del código (generación de `qa_pairs`, tokenización, entrenamiento y evaluación) queda idéntico; sólo la lectura inicial del JSON cambia de “archivo subido a Colab” a “archivo dentro de `/kaggle/input…`”.

Así que en resumen: modifica la celda de carga de datos (Celda 7 en el notebook) para apuntar al path de Kaggle, y, si lo deseas, añade los comandos de descarga de Kaggle en un bloque anterior. Todo lo demás permanece igual.
