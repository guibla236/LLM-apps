# Snapshot de `plans/`

Copia de lectura del repo git anidado `plans/` del proyecto original, sin su carpeta `.git`.
El historial está resumido en `HISTORIAL_PLANS.txt`.

**Los links relativos de estos archivos son los originales** y pueden aparecer rotos: apuntan a
`../RAG_DATASET_MIGRATION_PLAN.md`, `../../api/...`, etc., que en el repo real existen un nivel más
arriba. Para resolverlos, tomá `docs/handoff/planes/` como equivalente a `<repo>/plans/` y subí los
niveles que correspondan.

Los archivos tienen además 3 modificaciones locales sin commitear en el original
(`MILESTONES.md`, `M4_SearchOptimization/00_...`, `M6_HybridInference/20_...`): este snapshot las
incluye.
